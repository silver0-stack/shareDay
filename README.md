# 2. 프로젝트의 목적 및 용도
## 🤨이 프로젝트는 무엇을 위한 것인가
> 여자라면 생리대없이 외출했던 난감한 경험이 다들 한 번씩은 있습니다. 천하의 원수라도 선뜻 빌려준다는 생리대를 당장 내 옆에서 길을 걷고 있는 여자한테 빌려달라 하고 싶습니다. 하지만 타인한테 무작정 생리대를 빌려 달라고 하는 건 용기가 필요한 일이죠. 그리고 근처에 여성안심화장실은 어디 있을지도 궁금합니다.

이런 급박한 상황에서 필요한 앱에 대해 고민했고 쉐어데이는 도움이 필요한 사람과 도움을 줄 수 있는 사람을 매치시켜 주고 서초구청 홈페이지에 있는 여성안심화장실 위치를 지도에 마커로 표시했습니다.
## 😌어떤 문제를 해결할 수 있는가
생리대가 필요한 사람을 나눔으로써 도와줄 수 있고 도와준 사람은 포인트가 적립되어 가맹점에서 여성용품을 싸게 구입할 수 있습니다. 이렇게 도와준 사람에게는 포인트 적립으로 어플 사용을 독려함으로써 도움이 필요한 사람만 어플에 남는 우려 사항을 해결하고자 했습니다.
## 😉어떤 사람들이 이 프로젝트를 사용하면 좋은가
👉코틀린으로 안드로이드 프로젝트를 만들고 싶은 사람<br>
👉코틀린 기초를 공부하 사람<br>
👉파이어베이스로 서버 구현을 하고 싶은 사람
## 😙이 프로젝트는 어떻게 작동하는가
안드로이드 스튜디오에서 코틀린과 파이어베이스의 서버로 작동합니다.
